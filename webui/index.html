Publish your apps safely

This tool runs Traefik (a reverse proxy) in Docker Desktop and connects it to the Internet through a Cloudflare Tunnel. The tunnel is an outbound connection from this PC, so you do not open any ports on your router. Cloudflare receives HTTPS requests for your hostnames, can require a login (Cloudflare Access), and forwards allowed requests through the tunnel to Traefik, which sends each hostname to the right app: a Docker container, a program on this PC, or a device on your network.

Every change is shown as a preview first and only applied after you confirm it. Nothing outside this instance's own containers is started, stopped or modified.

Start with step 1, Connect Cloudflare, or skip it to install for local use only. Docker and Cloudflare are not changed until you confirm the installation in step 7.

    Cloudflare

    Optional but recommended: with a scoped API token this tool creates the tunnel, the DNS records, the tunnel routes and Cloudflare Access applications for you, always after a preview and your confirmation. It never deletes anything it did not create, and existing DNS records are only replaced after a separate confirmation.

    1. API token

    The token needs only these permissions. Limit it to the account and domains this PC should manage.

    • Zone · Zone · Read, and Zone · DNS · Edit
    • Account · Cloudflare Tunnel · Edit
    • Account · Access: Apps and Policies · Edit (optional, for automatic Access)
    Create Cloudflare API Token

    Cloudflare will display your API token when you create it. Copy it before closing that page. For security, Cloudflare won't display the same secret again. If you lose it, revoke or delete the old token and create a replacement.

    The token is encrypted with Windows DPAPI for your Windows account and stored in secrets\cloudflare_api.dpapi. It is never shown again or sent back to the browser.

    2. Account and tunnel

    A tunnel is the private connection between Cloudflare and this PC. Use one tunnel per proxy instance. Choose an existing tunnel managed from the dashboard, or create a new one.

    3. Connector (cloudflared)

    The cloudflared container of this instance keeps the tunnel connected. This step downloads the selected tunnel's connector token into secrets\cloudflare_tunnel_token and starts (or restarts) only this instance's cloudflared container.

    Streaming media
    
        
    Cloudflare's terms restrict serving video or large amounts of non-HTML content through its proxy and tunnels
          unless you use a Cloudflare media product, and uploads are capped at 100 MB on Free/Pro plans. Media servers such as
          Plex or Jellyfin work for browsing and light use, but heavy streaming should use the app's own remote access or a
          private network (WARP / Cloudflare One).
    
      
    
    
    

    
    
    
      
    Backups and rollback
    
      
    Every applied change first saves the previous Traefik routes and service registry. Restoring a backup
        saves the current state as well, so a rollback can itself be undone. Cloudflare resources are not rolled back.
